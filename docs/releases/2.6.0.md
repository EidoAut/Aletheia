# Aletheia 2.6.0

Aletheia 2.6.0 replaces the compact shell header with a DPI-safe desktop layout. The page title, subtitle, active-dataset name, dataset metadata and EIDO/Aletheia wordmark now use deterministic vertical space instead of percentage rows that could collapse under Windows display scaling.

## Desktop changes

- Shared 116-pixel logical header row for the analytical header and sidebar identity block.
- Explicit title, subtitle, dataset-caption and dataset-metadata rows with removed implicit label margins.
- Wider page-context and sidebar regions to retain hierarchy without truncating the main actions.
- Vertically centered, fixed four-column action area with a stable Run Arena/Cancel slot.
- DPI-scaled vector brand mark and automatic fitting of the company caption.
- Tooltips retain the complete page title and subtitle when horizontal ellipsis is required.
- Smoke-test coverage compares label client heights against `TextRenderer` measurements.

## Scientific scope

No analytical, simulation, annualization, forecast, validation, ranking, provider or persistence behavior changes in this release.

- Product version: `2.6.0`
- Scientific version: `2.5.0-irregular-cadence`
