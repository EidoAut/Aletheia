# Historical Analogues

Historical analogue pages compare the current dynamic state with previous states that used the same
state schema.

## What It Consumes

- current dynamic state;
- historical state sequence;
- schema fingerprint;
- distance metric over comparable state dimensions.

## What It Displays

- nearest historical state dates;
- distance or similarity information;
- forward outcomes over 30, 90, and 180 calendar days where available;
- analogue paths for charting.

## Interpretation

Analogues answer: "When the fund looked similar before, what happened next?" They do not prove that
the same future will occur. They are most useful as evidence beside risk, forecasts, and validation.

## Important Limits

- Future-date matches are excluded.
- Schema incompatibility prevents comparison.
- Analogue timing uses robust scaling so large-unit features do not dominate solely because of units.
