# Terminology

| Term | Meaning |
| --- | --- |
| Actionability | Whether evidence is usable as a current decision summary. |
| Arena | Walk-forward model comparison under common rules. |
| Brier score | Probability-forecast squared error. Lower is better. |
| Calibration | Agreement between predicted probabilities and observed frequencies. |
| Common support | Evaluation events shared by models for a metric family. |
| Current attractiveness | Present opportunity score, separate from long-run fund score. |
| Dataset fingerprint | SHA-256 identity for the loaded NAV series. |
| Forecast capability | Declared outputs a model truly supports. |
| Horizon | Explicit future window in calendar days or observations. |
| OOD | Out-of-distribution; current features are unusual relative to training support. |
| Prediction ledger | Immutable prediction and evaluation storage. |
| ReliabilityIndex | Validation-support index, not probability of correctness. |
| Scientific version | Methodology/reproducibility version stamped into scientific metadata. |
| Signal qualification | Confirmed, tentative, or unavailable status behind a visible label. |
| Triple barrier | Timing label based on upside, downside, and vertical time barriers. |
| Walk-forward | Historical evaluation that trains only on data available at each cutoff. |
